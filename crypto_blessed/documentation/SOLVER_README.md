## Overview

This repository contains a complete solution for the "Blessed" CTF challenge, a hard-difficulty cryptographic challenge worth 1000 points. The challenge requires exploiting three interconnected cryptographic vulnerabilities to authenticate as a "blessed" robot and retrieve the flag.

### Challenge Scenario

In a city governed by automated robots, you must hack into the central control hub by:
1. **Forging BLS signatures** using a rogue key attack
2. **Cracking an EC-LCG PRNG** using lattice-based cryptanalysis
3. **Cheating a Zero-Knowledge Proof** verification by predicting challenge bits

## Quick Start

### Prerequisites

- Python 3.11+
- SageMath (required for elliptic curve cryptography)
- Linux, macOS, or WSL (Windows Subsystem for Linux)

### Installation

**Option 1: Automated Setup (Recommended)**
```bash
# Clone the repository
git clone https://github.com/Om-Gajjar/blessed.git
cd blessed

# Run the setup script
bash setup.sh

# Activate sage environment if using conda
conda activate sage
```

**Option 2: Manual Setup**
```bash
# Install SageMath
sudo apt install sagemath  # Ubuntu/Debian
# OR
conda create -n sage -c conda-forge sage python=3.11

# Install Python dependencies
pip install -r requirements.txt
```

### Usage

**Run against CTF server:**
```bash
python solver.py
```

**Run with custom server:**
```bash
CTF_HOST=your.server.ip CTF_PORT=12345 python solver.py
```

**Enable debug mode:**
```bash
DEBUG=1 python solver.py
```

**Test locally:**
```bash
# Terminal 1: Start local server
python server.py

# Terminal 2: Run solver against local server
CTF_HOST=127.0.0.1 CTF_PORT=<port> python solver.py
```

## How It Works

The solver exploits three cryptographic vulnerabilities in sequence:

### 1. BLS Rogue Key Attack 🔓
- **Target**: BLS signature aggregation scheme
- **Method**: Manipulates public key during aggregation to forge valid signatures
- **Impact**: Bypasses authentication without knowing the secret key

### 2. EC-LCG PRNG Crack 🎲
- **Target**: Elliptic Curve Linear Congruential Generator
- **Method**: Uses lattice reduction (LLL algorithm) to recover internal state
- **Impact**: Predicts all future "random" values generated by the server

### 3. Zero-Knowledge Proof Cheating 🎭
- **Target**: Schnorr-like ZKP verification (64 rounds)
- **Method**: Predicts challenge bits using cracked PRNG and provides valid responses
- **Impact**: Proves knowledge of secret key without actually knowing it

For detailed technical explanations, see [SOLUTION.md](SOLUTION.md).
