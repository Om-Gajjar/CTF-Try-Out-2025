KEY VULNERABILITIES
═══════════════════════════════════════════════════════════════════════════

1. ⚠️  wkhtmltopdf follows HTTP redirects to file:// (CVE-2020-21365)
2. ⚠️  JWT secret stored in readable .env file
3. ⚠️  Regex bypass with newline (\n character)
4. ⚠️  SQL injection in GraphQL query
5. ⚠️  MySQL INTO OUTFILE allows arbitrary file write
6. ⚠️  EJS template allows arbitrary code execution
7. ⚠️  SUID /readflag binary executes as root


MITIGATIONS
═══════════════════════════════════════════════════════════════════════════

✅ Use --disable-local-file-access for wkhtmltopdf
✅ Don't follow redirects to non-HTTP protocols
✅ Use environment variables, not .env files in production
✅ Rotate JWT secrets regularly
✅ Use multiline mode for regex: /^.*[...]$/m
✅ Use parameterized queries, never string interpolation
✅ Restrict MySQL file write permissions
✅ Validate and sanitize template content
✅ Don't allow user-controlled template paths
✅ Minimize SUID binaries, use capabilities instead
